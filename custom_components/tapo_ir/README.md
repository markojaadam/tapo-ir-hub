# Tapo IR Hub integration package

This package supports two local connection modes:

- a recommended adapter over Home Assistant's loaded core TP-Link session;
- a backward-compatible direct `plugp100` connection.

It exposes normalized key buttons, remote entities, diagnostic sensors,
conservative AC climate control, verified management transactions, and the
admin-only WebSocket backend for the bundled Tapo IR Control Panel card.

See the repository [README](../../README.md) for installation, safety, card
behavior, migration, and troubleshooting details.
